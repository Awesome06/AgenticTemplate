# Security Policy

## Supported Versions

Only the latest active minor release receives security updates.

| Version | Supported          |
| :---    | :---               |
| latest  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please **DO NOT** open a public issue.

Instead, please report vulnerabilities privately via:
1. GitHub Private Vulnerability Reporting on this repository.
2. Direct email to the project maintainers.

Please include:
- A clear description of the vulnerability.
- Steps to reproduce or a minimal proof of concept.
- Potential impact and affected subsystems.

Maintainers will acknowledge receipt within 48 hours and coordinate remediation.
