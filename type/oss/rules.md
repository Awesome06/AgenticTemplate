# External OSS Contribution Rules

1. **Red-Test Reproducer Gate:** Never edit source files without an isolated failing test proving the issue.
2. **Taste Mimicry:** Match upstream formatting, error conventions, and naming patterns exactly.
3. **Diff Discipline:** Keep diffs minimal, clean, and strictly scoped to the bug or feature.
4. **No Reopening:** Do not attempt to reopen closed pull requests.
