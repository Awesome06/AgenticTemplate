# Academic Research Paper Rules

1. **Double-Blind Integrity:** Never leak institutional identities, grant numbers, or local user paths.
2. **Statistical Invariants:** Always compute non-parametric effect sizes (Vargha-Delaney A12) and Wilson score intervals for empirical claims.
3. **Reproducibility Tiers:** Ensure all pipeline scripts implement `--dry-run`, `--sample`, and `--full`.
4. **Placeholder Protocol:** Use `{metric_originTech}` format for any unavailable metric.
