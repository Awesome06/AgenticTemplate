# Personal Project

A private application, tool, or rapid prototype workspace built with Antigravity agentic workflows.

## Getting Started

### Prerequisites
- Active language toolchain (e.g., Python `uv`, Rust `cargo`, or Node `pnpm`).
- Antigravity agent environment with central `agent-skills-vault`.

### Setup
Run the workspace setup to configure hooks and local dynamic skill junctions:
```powershell
.\.agent\setup.ps1
```

### Development
1. Run local tests and linters before committing.
2. Maintain architecture notes in `wiki/` when contracts or invariants evolve.
