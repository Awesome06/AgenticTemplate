# Personal Project Rules

1. **Velocity First:** Rapid prototyping and personal harness govern. No artificial gating or bureaucratic red-test tripwires.
2. **Local Parity:** Run linters and tests locally via native package runners (`pytest`, `cargo test`, `vitest`).
3. **Clean Git Tree:** Dynamic agent junctions and leases remain excluded in `.git/info/exclude`. `AGENTS.md` remains committed.
