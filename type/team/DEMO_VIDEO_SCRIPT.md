# 120-Second Competition Demo Script

## Hook (0:00 - 0:20)
- **Problem Statement:** What critical pain point does this system solve in 1 sentence?
- **Current Broken Alternative:** Why do status-quo approaches fail?
- **The Core Breakthrough:** Introduce the product name and its unique insight.

## Architecture & Live Demo (0:20 - 1:15)
- **Step 1: Ingestion / Action:** Show the primary user action in the live UI or CLI.
- **Step 2: Engine Processing:** Highlight backend streaming, vector search, or consensus engine.
- **Step 3: Tangible Output:** Reveal the concrete, high-value result generated in real time.

## Technology Stack & Sponsor Tracks (1:15 - 1:40)
- **Track 1:** How this project directly addresses Track 1 requirements.
- **Track 2:** Integration with partner APIs / SDKs.
- **Resilience:** Mention concurrency benchmarks or automated verification gates.

## Call to Action & Conclusion (1:40 - 2:00)
- **Where to Try It:** URL / repository link.
- **Roadmap:** What ships next.
